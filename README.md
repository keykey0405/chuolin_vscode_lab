# chuolin_vscode_lab
学习C++吹泡泡！！
学习C++的VSCode实验仓库，使用 MinGW-w64 编译调试。

## 📂 目录结构
demo/
├─ simple_demo/ # 单文件 C++ 入门示例 hello.cpp
├─ multiple_demo/ # 多文件项目（头文件 + 源文件分离）
├─ .vscode/ # VSCode 编译、调试配置
└─ .gitignore # 忽略编译产物 *.exe

## 🚀 编译运行
打开对应项目文件夹，快捷键 `Ctrl+Shift+B` 编译，运行生成的 `.exe`。
